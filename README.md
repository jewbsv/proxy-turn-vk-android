# qWDTT

Тоннель WireGuard с телефона на ваш VPS через **TURN-релей VK**. Для сети снаружи это выглядит как обычный WebRTC-звонок, а не как VPN.

**Пакет:** `net.qwdtt.client.jewbsv` · **Версия:** 1.4.35

Полностью совместим с сервером и протоколом **WDTT** ([amurcanov/proxy-turn-vk-android](https://github.com/amurcanov/proxy-turn-vk-android)): `wdtt-server`, ссылки `wdtt://`, WRAP/RTP и VK-авторизация работают взаимозаменяемо — можно поднять VPS оригинальным деплоем и подключиться qWDTT.

## 🤔 Что это

Утилита туннелирует трафик с телефона на ваш сервер. Отличие от обычного VPN — транспорт:

- клиент получает временные **TURN**-креды из звонка VK;
- поднимает **DTLS** через TURN-релей VK;
- пакеты заворачиваются в **RTP** и шифруются **WRAP** (ChaCha20-Poly1305);
- на телефоне — системный **WireGuard** (`VpnService`), на сервере — `wdtt-server`.

```
Телефон                       VK TURN relay                VPS
┌──────────────┐   RTP+WRAP    ┌──────────┐  DTLS+WRAP   ┌──────────────┐
│ WireGuard    │ ────────────► │  relay   │ ───────────► │ wdtt-server  │
│ Go-клиент    │               │   (VK)   │              │  WireGuard   │
└──────────────┘               └──────────┘              └──────────────┘
```

## ✨ Возможности

- **Профили** — несколько конфигов, папки, перетаскивание, быстрый выбор на «Туннеле».
- **Подписки** — раздача профилей по HTTPS-JSON, автообновление, трафик на карточке.
- **Импорт** — `wdtt://`, расширенные `qwdtt://`, QR, пакетный JSON, файл `.qwdtt`.
- **VK** — анонимный вход или через аккаунт (WebView, перехват `turn_server`).
- **Туннель** — логи, статистика, пинг до сервера, смена потоков, DNS, обход IP/доменов и исключения приложений.
- **Деплой сервера** — установка `wdtt-server` на VPS по SSH прямо с телефона.
- **Удобства** — виджет, плитка Quick Settings, watchdog при смене сети, статус пароля в карточке.

> Чего нет в оригинальном WDTT: профили, подписки, глобальные VK-хеши, пинг, вход через аккаунт VK, виджет и плитка. Протокол при этом общий.

## 🚀 Быстрый старт

1. Установите APK из [релизов](https://github.com/jewbsv/proxy-turn-vk-android/releases).
2. Настройте сервер: вкладка **Деплой** или уже готовый VPS с `wdtt-server`.
3. Запустите звонок VK: ссылка `vk.com/call/join/…` или только хеш после `/join/`.
4. Импортируйте профиль: `wdtt://…`, `qwdtt://…`, QR или заполните вручную.
5. Нажмите **Подключить** и разрешите VPN.

> ⚠️ Завершайте звонок **«Просто завершить»**, а не «Завершить для всех» — иначе хеш умрёт.
> До **4 хешей** в профиле — нагрузка распределяется между звонками.

## 🔗 Форматы ссылок

**WDTT** — официальный, поддерживается полностью (QR, буфер, бот сервера):

```text
wdtt://<IP>:<dtls_port>:<wg_port>:<local_port>:<пароль>:<vk_hash>
```

| Поле | По умолчанию | Описание |
|------|--------------|----------|
| `dtls_port` | `56000` | UDP-порт DTLS на VPS |
| `wg_port` | `56001` | внутренний WireGuard-порт сервера |
| `local_port` | `9000` | локальный UDP на Android |
| `пароль` | — | пароль подключения (WRAP + авторизация) |
| `vk_hash` | — | хеш звонка; `:` внутри хеша склеивается |

**qWDTT** — расширенный, удобнее для профилей (имя, несколько хешей, потоки):

```text
qwdtt://config?name=Дом&peer=1.2.3.4:56000&hashes=хеш1,хеш2&workers=18&port=9000&pass=секрет
```

**JSON / `.qwdtt`** — профили описываются простым JSON (`name`, `peer`, `hashes`, `workers`, `port`, `password`; альтернативы: `vkHashes`, `workersPerHash`, `listenPort`, `pass`). Файл `.qwdtt` — URI или JSON внутри.

**Подписки** — один HTTPS-JSON раздаёт список профилей; приложение обновляет папку по кнопке или периодически.

```json
{
  "subscriptionName": "Мой сервер",
  "description": "Подписка · до 24.08.2026",
  "trafficUsedMb": 76.8,
  "trafficLimitMb": 102912,
  "profiles": [
    { "name": "Сервер 1", "peer": "203.0.113.10:56000", "hashes": "vk_hash_1", "workers": 18, "port": 9000, "password": "секрет" }
  ]
}
```

## 🖥 Сервер

`server.go` → бинарь `wdtt-server`: DTLS, WRAP/RTP, выдача WG-конфига, `/etc/wdtt/passwords.json`, Telegram-бот.

| Параметр | Значение |
|----------|----------|
| `56000/udp` | DTLS-приём клиентов |
| `56001/udp` | WireGuard внутри сервера |
| `9000/udp` | локальный порт на Android |
| `10.66.0.0/16` | подсеть клиентов (типичный адрес `10.66.66.x`) |

Пароли: главный + до 10 пользовательских (срок, привязка к устройству). Обновление без рестарта: правка JSON → `kill -HUP $(pidof wdtt-server)`.

## 🛠 Сборка

```bash
export ANDROID_NDK_HOME=/path/to/android-ndk
./scripts/build-native-libs.sh
./gradlew :app:assembleDebug
```

Одна ABI: `./scripts/build-go-lib.sh arm64-v8a`. Имена выходных APK: `qWDTT-<abi>.apk` (например `qWDTT-arm64-v8a.apk`, `qWDTT-x86_64.apk`, `qWDTT-universal.apk`).

## 📁 Структура репозитория

```text

go_client/  Нативный клиент → libclient.so
server.go   Серверная часть (совместим с WDTT)
scripts/    Сборка Go под Android ABI
```
